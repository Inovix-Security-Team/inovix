# Inovix UI Guidelines

## 1. Design Principles

The Inovix interface should be:

- Professional
- Clean and easy to understand
- Consistent across all pages
- Security-focused
- Responsive on different screen sizes
- Accessible to users

## 2. Typography

Use a consistent font throughout the application.

- Headings should be clear and easy to read.
- Body text should have a comfortable size.
- Important security information should be easy to notice.
- Use consistent font weights for headings, labels, and normal text.

## 3. Spacing

Use a consistent spacing scale:

- 4px
- 8px
- 12px
- 16px
- 24px
- 32px
- 48px

Avoid using random spacing values.

## 4. Buttons

Buttons should have:

- Consistent height
- Consistent padding
- Clear text
- Hover state
- Focus state
- Disabled state

Supported button variants:

- Primary
- Secondary
- Danger
- Ghost

## 5. Inputs

Inputs should have:

- Clear labels
- Placeholder text when required
- Consistent height
- Focus state
- Error state
- Disabled state

All inputs should have visible labels.

## 6. Cards

Cards should use:

- Consistent padding
- Consistent border radius
- Subtle shadows or borders
- Clear headings
- Readable content

Cards can be used for:

- Risk Score
- Security Events
- Latest Incidents
- Affected Assets
- Threat Intelligence
- Analysis Results

## 7. Security Status

Inovix uses four main security statuses:

- SAFE
- SUSPICIOUS
- MALICIOUS
- UNKNOWN

Status should not be communicated by color alone. Always display the status text.

## 8. Risk and Severity

Risk is represented as a score from 0 to 100.

Severity levels are:

- LOW
- MEDIUM
- HIGH
- CRITICAL

Risk score and severity should be displayed separately.

## 9. Responsive Design

The UI should work properly on:

- Desktop
- Tablet
- Mobile

Important security information must remain visible and readable on smaller screens.

## 10. Accessibility

Follow these basic accessibility rules:

- Use real button elements for buttons.
- Provide labels for inputs.
- Do not rely on color alone to communicate meaning.
- Provide visible keyboard focus states.
- Maintain readable contrast.
- Use clear text such as "MALICIOUS" instead of only using an icon.

## 11. Animations

Animations should be simple and useful.

Avoid unnecessary animations and visual effects.
